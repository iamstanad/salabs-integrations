# S.A Labs n8n templates

Import into n8n with **⋯ (top right) → Import from file**. You need the `n8n-nodes-salabs` community node and an S.A Labs API key. Each template has a sticky note with setup steps.

| File | What it does | Also needs |
|------|--------------|------------|
| `01-video-to-blog-post.json` | Form upload → transcribe → AI blog post shown in the form | Google Gemini key (free) or any chat model |
| `02-urls-to-ai-summary-google-sheet.json` | URL list → scrape → AI summary → Google Sheets row | Gemini, Google Sheets |
| `03-script-to-voiceover.json` | Form with script + voice → MP3 download | nothing else |
| `04-podcast-to-transcript-and-subtitles.json` | Podcast RSS → transcribe latest episode → SRT to Google Drive | Google Drive |
| `05-competitor-website-monitor.json` | Daily scrape → detect changes → AI summary email | Gemini, Gmail |
| `06-ai-agent-with-salabs-tools.json` | Chat agent using S.A Labs as tools (read web, make audio, transcribe) | Gemini |

The JSON files are generated by `build_templates.py`. Edit that script, then run it, rather than editing the JSON by hand.

Tested on n8n 2.47.7: templates 1–5 ran end to end against the S.A Labs API, with the Gemini, Google and Gmail steps switched off because they need your own accounts. Template 6 imports cleanly; it needs a chat model to run.
